# Shoot Checklist — 40 Poses

Pura shoot **1 din** mein ho jaana chahiye. Raaz ye hai: pose ke naam ke order mein shoot NA karo — **body position ke block** mein karo. Isse mat/camera/light ek baar set hota hai aur 40 poses 4–5 ghante mein nikal jaate hain.

---

## Setup (ek baar, 30 min)

| Cheez | Kya karna hai |
|---|---|
| Background | Plain wall — off-white, light grey ya beige. Koi poster/almari/door nahi |
| Light | Khidki se **saamne se** light. Khidki peeche mat rakho (silhouette ban jaata hai). Shaam 4–6 baje best, ya 1 softbox |
| Camera | Phone, **tripod pe**, chest height, **4K 30fps** (baad mein crop karne ki jagah milti hai) |
| Orientation | **Vertical 9:16** — app aur Reels dono isi mein chahiye |
| Mat | Plain, background se contrast karta hua (light wall → dark mat) |
| Kapde | **Solid colour**, fitted, no logo/print. Top mat se alag colour. Barefoot |
| Audio | Record karte waqt audio ki fikar nahi — voice alag se record hogi |
| Phone settings | Airplane mode ON, grid lines ON, auto-lock OFF, focus+exposure **lock** karo (screen pe tap-hold) |

## Framing rule (sabse important)

- **Poora body frame mein** — sir ke upar ~10% jagah, pair ke neeche ~5%
- Camera **ek baar set** karo poore block ke liye, beech mein mat hilao
- Har pose mein **2 angle**: `front` (seedha saamne) aur `side` (90° daayein)
- Side angle ke liye tripod ghumao, **pose dubara karo** — crop se kaam nahi chalega

## Har pose kaise shoot karna hai (10 second)

```
0–3 sec   pose mein jaana (entry transition)
3–10 sec  pose hold — EKDUM STILL, saans chalti rahe
```

App mein 3–10 sec ka hissa **loop** hoga, isliye hold ke dauraan hilna mat — warna loop mein jhatka dikhega.

Har pose ke **2 take** lo. Dusra take pehle se behtar hota hai.

## File naming (ye zaroor follow karo, warna baad mein 160 files mein confuse ho jaoge)

```
<id>_<slug>_<angle>_<take>.mp4

07_tadasana_front_1.mp4
07_tadasana_side_1.mp4
21_bhujangasana_front_2.mp4
```

ID aur slug `poses.csv` se copy karo. 40 poses × 2 angle × 2 take = **160 clips**.

## Shoot ke baad (same din karo)

| ☐ | Kaam |
|---|---|
| ☐ | Saare clips phone se laptop pe, `raw/` folder mein |
| ☐ | Har pose ka **best take** chuno → `selected/` folder |
| ☐ | Trim: sirf hold wala hissa (3–10 sec), loop-friendly |
| ☐ | Compress: 1080×1920, H.264, CRF 28, **no audio** → target 300–500 KB |
| ☐ | Ek 1-sec poster frame (JPG) har pose ka |
| ☐ | `poses.csv` mein `clip_url` column bharo |

**Compress command** (ffmpeg, ek baar sab pe chala do):
```bash
for f in selected/*.mp4; do
  ffmpeg -i "$f" -an -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920" \
    -c:v libx264 -crf 28 -preset slow -movflags +faststart "final/$(basename "$f")"
done
```
