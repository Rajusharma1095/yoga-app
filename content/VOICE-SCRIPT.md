# Voice Recording Script — 40 Poses

Har pose ke **3 cue**: ENTRY (kaise jaana hai) · HOLD (kya dhyaan rakhna hai) · EXIT (kaise bahar aana hai).
40 poses × 3 cue × 2 bhasha = **240 clips**. Sunke lagta hai zyada hai — asal mein **~45 minute** ka kaam hai, kyunki har cue 3–5 second ka hai.

## Recording setup

| | |
|---|---|
| Kahan | Chhota kamra, almari ke paas (echo kam). Bathroom mein nahi |
| Mic | Phone ke earphone ka mic kaafi hai. Phone 15 cm door, thoda side mein (saans ki awaaz na aaye) |
| App | Phone ka voice recorder, ya laptop pe Audacity (free) |
| Tone | **Dhire, shaant, warm.** Gym trainer wali energy nahi — yoga wali. 10% slow bolo |
| Pause | Har cue ke baad **2 second chup** raho — cut karna asaan ho jaata hai |
| Order | Pehle poori Hindi (120 cue), phir poori English. Bhasha switch karte rehne se tone badal jaata hai |
| Naming | `07_tadasana_hi_entry.mp3`, `07_tadasana_en_hold.mp3` |

> **Tip:** ek hi file mein sab record karo, baad mein cut karo. Har cue se pehle apna pose ID bol do ("saat — entry") — editing mein 10x asaan ho jaata hai. Wo ID wala hissa cut kar dena.

| | | EXIT | हाथ नीचे, दूसरी तरफ़ | Arms down, other side |

| | | HOLD | दाएँ हाथ की उँगलियों को देखें | Look past your right fingertips |
| | | EXIT | पैर सीधा करें, दूसरी तरफ़ | Straighten the leg, other side |

| | | HOLD | एड़ी से उँगलियों तक एक लंबी रेखा | One long line, heel to fingertips |
| | | EXIT | ऊपर आएँ, पैर बदलें | Come up, switch sides |
| 13 | Trikonasana | ENTRY | पैर चौड़े, दायाँ हाथ पिंडली पर | Feet wide, right hand to your shin |

| 17 | Prasarita | ENTRY | पैर चौड़े, कूल्हे से आगे झुकें | Feet wide, fold from the hips |
| | | HOLD | सिर लटका, कंधे ढीले | Head heavy, shoulders soft |
| | | EXIT | हाथ कूल्हे पर, धीरे-धीरे उठें | Hands to hips, come up slowly |
